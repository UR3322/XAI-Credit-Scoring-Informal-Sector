Explainable AI-Based Credit Scoring for Pakistan's Informal Sector
This repository contains the implementation of a documentation-free credit scoring framework using XGBoost and SHAP.

Project Overview
Objective: Provide financial identities to the "credit invisible" population in Pakistan.

Accuracy: 89%.

Key Technologies: Python, XGBoost, SHAP (Explainable AI), Scikit-Learn.

How it Works
Data: Uses alternative digital footprints (mobile wallet transactions, utility patterns).

Model: XGBoost classifies risk levels.

Explainability: SHAP provides human-readable justifications for every decision.

Contents
code/: Model training and evaluation scripts.

data/: The synthetic dataset used for this research.

results/: Visualizations of model performance.
